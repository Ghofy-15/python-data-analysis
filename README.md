# Analyse de Données Statistiques avec Python
## Présentation du Projet
Ce projet consiste en un script Python permettant d'effectuer des calcules statistiques de base sur un ensemble de données de notes d'étudiants.
Il permet d'automatiser l'extraction d'indicateurs clés:
- Calcul de la moyenne générale
- Identification de la note maximale
- Identification de la note minimale
# Structure du code
Le script prend en entrée une liste numérique et applique les fonctions natives de Python('sum()', 'len()', 'max()', 'min()')pour générer un rapport synthétique en Python
# exemple de résultat obtenu : 
***Rapport d'analyse de données***
Série de notes : [14, 16, 12, 15, 13, 17]
Moyenne générale : 14.50
Note maximale : 17
Note minimale : 12
